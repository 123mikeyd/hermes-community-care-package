# Misty Mountain · v0.1.0-prototype

An editable community testing and learning kit. See the [package README](../README.md) for contents, controls, limitations and the four learning challenges, and [NOTICE](../NOTICE.md) for sharing scope.

Import `project.godot` in Godot 4.7.2 and press F5 after import completes. Optional Windows shortcuts: `PLAY.cmd` / `EDIT.cmd`. No accounts, paid plugins or Blender are needed to play.

Start reading `main.gd` for movement, character switching, camera and boundaries; `interactions.gd` for token/checkpoint/display interaction; `Main.tscn` for terrain/car instances; `calibration.json` for model scale and clip offsets. The players and examples are created at runtime.

# Misty Mountain · Playable Starter

Walk around as **Teknium or Doge Man**, collect a token and try the checkpoint. Then change something in your own copy.

**[Download the complete starter →](https://github.com/123mikeyd/hermes-community-care-package/releases/tag/v0.1.0-prototype)**

## Start here

1. Download and extract the complete starter ZIP from the release above.
2. Install the standard **Godot editor**. The tested version is 4.7.2 on Windows 11; the editor is not bundled.
3. Import **`starter/project.godot`** in Godot, wait for import to finish, and press **F5**.

**[Step-by-step setup and controls →](QUICKSTART.md)**

No Blender, Hermes account or paid plugin is needed to play. This is a desktop editor project, not a click-to-play browser game.

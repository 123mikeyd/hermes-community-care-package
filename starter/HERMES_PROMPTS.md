# Optional conversation prompts

For a person to copy into an ordinary Hermes conversation. This is not agent configuration, an installed skill, or an automatically executed instruction file. Replace `[my extracted copy]` with your own folder.

## Understand the example

> In [my extracted copy], explain how E selects a nearby target, how pickup-once is enforced, and why R differs from F. Read the README and matching Godot scripts. Don't edit yet. Point me to the small functions I can learn from.

## Make one bounded change

> Help me try one lighting value in a copy of this project. Preserve the imported artwork and keep a before/after screenshot. Run the existing verification and explain how to undo only my change. No extra mechanics.

## Learn an interaction test

> Help me test the collectible with actual engine input: outside range, inside range, held E, repeated E, respawn, full reset, then collect again. Explain why hiding a mesh is different from preventing duplicate rewards. Preserve Q/C camera controls.

## Bring in my own Blender prop

> Help me export one prop I own from a separate working Blender file into this experiment copy. Keep the original and any live Blender session untouched. Verify selected-only GLB export, textures, dimensions and ground placement. No whole-scene dump or character retargeting.

## Diagnose a failure

> My Godot version is [version], OS is [OS], exact error is [paste]. Reproduce it in this copy before proposing a fix. Show a focused failing test, the smallest repair and real rerun output. Do not touch other projects.

## Prepare an experiment handoff

> Review the manifest and NOTICE. Check a fresh ZIP for missing files and private paths. Explain my changes and remaining prototype limitations. Do not upload my experiment without my approval.

A helpful result is short: change, verified result, remaining limit and undo path. A screenshot demonstrates appearance, not asset rights.
